PILLAR 01 // INTELLIGENT ROUTING

TOPAZ Cost-Utility-Value Router

Prevents over-spending frontier compute on routine scanning. TOPAZ evaluates candidate local models (lightweight, mid, heavy) and scores them against task estimates using the CUV objective function:

CUV = (P(success) × Stealth) / (Cost_per_token × Execution_Time)
PILLAR 02 // EPISODIC MEMORY

CSIM "Vaccine Registry"

Successful exploits and verified remediation patches from PASS verdicts are embedded and committed into a local vector registry. Subsequent rounds utilize cosine similarity lookups to warm-start task estimators and accelerate remediation.

Similarity Threshold = 0.2 // Fully Local Embedding Vectors
PILLAR 03 // PROGRAM ANALYSIS

Multi-Graph Code Representations

Target code is analyzed using Tree-Sitter and NetworkX to produce Abstract Syntax Trees (AST), Control Flow Graphs (CFG), Data Flow Graphs (DFG), and combined Program Dependence Graphs (PDG) for exact vulnerability localization.

Graph Bundle = { AST, CFG, DFG, PDG, SourceCode }
PILLAR 04 // ENVIRONMENT ISOLATION

Sealed Network Fabric & Telemetry

Sandboxed targets run within Mininet network fabrics and isolated network namespaces with iptables forward-drop enforcement. Dedicated telemetry containers stream eBPF socket lifecycle events without leaking packets to the host.

Network Isolation: iptables -I FORWARD -s [ns] -j DROP
